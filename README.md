# geolocalizacao_acudes_dnocs
Esse conjunto de scripts geolocaliza os açudes públicos administrados ou construídos pelo DNOCS (Departamento Nacional de Obras contra as Secas) e cria arquivos em formato GeoJson que podem ser colocados no QGIS para geolocalização dos mesmos. A estrutura do código pode ser usada para outras geolocalizações de açudes.
